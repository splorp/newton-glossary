Title: VSNewt

----

Date: 03 November 2026

----

Text:

An extension developed by (link: /sources/matthias-melcher text: Matthias Melcher) that provides a way to write, (link: /terms/build text: build), run, and debug (link: /terms/newtonscript text: NewtonScript) using Microsoft’s [Visual Studio Code](https://code.visualstudio.com/).

Built around Simon Bell’s (link: /terms/newton-framework text: Newton Framework), VSNewt utilizes a program called (link: /terms/newtc text: newtc) to provide a NewtonScript (link: /terms/compiler text: compiler), runtime, and (link: /terms/debugger text: debugger).

Along with the ability build and debug (link: /terms/package text: packages) from NewtonScript source code, VSNewt can also decompile existing packages back into NewtonScript.
