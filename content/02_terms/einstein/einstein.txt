Title: Einstein

----

Date: 10 September 2017

----

Text:

An open source software emulator originally developed by (link: /sources/paul-guyot text: Paul Guyot) that allows (link: /terms/newton-os text: Newton OS) to run on other (link: /terms/operating-system text: operating systems) such as Mac OS X, iOS, and Linux.

The (link: /terms/rom-extension text: ROM extension) created for Einstein is identified by the (link: /terms/rex text: .rex) filename extension and contains a collection of tools for interfacing with the host (link: /terms/operating-system text: operating system). These tools include various (link: /terms/device-driver text: device drivers), the Desktop Connection Library ((link: /terms/dcl text: DCL)) framework, Eckhart Köppen’s (link: /terms/tntk text: tntk) NewtonScript (link: /terms/compiler text: compiler) and (link: /terms/packager text: packager), as well as Frank Gruendel’s (link: /terms/newttest text: NewtTest) utility.
