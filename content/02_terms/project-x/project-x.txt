Text:

A Windows 95 “emulator” for (link: /terms/newton-os text: Newton OS) created by (link: /sources/nick-muller text: Nick Müller) of (link: /terms/logic-tools text: Logic Tools) as part of his (link: /terms/drunken-programmers-project text: Drunken Programmers Project).

Obviously put together as a joke, the software basically mimicked Windows crashing every time the user (link: /terms/tapped text: tapped) on a (link: /terms/user-interface text: user interface) element.
