Title: Smash Heap Tags

----

Date: 30 July 2026

----

Text:

A command located in the “Memory” menu of the (link: /terms/newtsbug text: NewtsBug) application.

Smash Heap Tags assigns all (link: /terms/tag text: tags) in the active (link: /terms/heap text: heap) window a value of `0x7fffffff` for debugging purposes. This process can be used to visualize how heap is allocated after running the command.
